# Roadmap

This roadmap describes the planned evolution of Ohtli.

The roadmap is organized into milestones. Each milestone delivers a coherent set of capabilities while preserving the stability of the framework.

---

# Milestone M1 — Core Specification

**Status:** Completed

Define the conceptual foundation of Ohtli.

## Deliverables

* Foundation
* Architecture
* Domain Model
* Execution System
* Filesystem
* Metadata
* Templates
* Views
* Automation
* Governance
* Glossary
* Versioning

**Release**

* `v1.0.0-alpha`

---

# Milestone M2 — Development Model

**Status:** In Progress

Define how Ohtli is developed and maintained.

## Deliverables

* Git branching workflow
* Pull request workflow
* Changelog
* Release management
* Issue templates
* GitHub labels
* GitHub milestones
* Development guidelines

# Milestone M3 — Reference Implementation

**Status:** Planned

## Deliverables

* Standard templates
* Metadata examples
* Sample workspace
* Example projects
* Example knowledge base

**Status:** Planned

# Long-Term Vision

Ohtli becomes a tool-independent Personal Operating Framework supported by multiple implementations, automation layers, and AI-assisted workflows while preserving a stable conceptual core.
