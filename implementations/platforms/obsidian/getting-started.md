# Getting Started

This guide explains how to start using the Ohtli Obsidian Implementation.

## Prerequisites

* Obsidian installed.
* Basic familiarity with Markdown.
* A local directory to store your vault.

## Choose a Vault Location

Ohtli does not require a fixed vault location.

You may either:

* use the bundled Reference Vault, or
* create your own vault in any location and copy the required files.

Examples:

```text
~/Documents/Ohtli
~/Vaults/Personal
D:\Notes\Ohtli
```

## Open the Vault

Open your chosen vault using Obsidian.

If you are using the bundled Reference Vault, select the `reference-vault/` directory.

## Install Recommended Plugins

The recommended plugins are documented in the `plugins/` directory.

Installing them is optional but recommended to enable the complete Ohtli experience.

## Verify the Installation

Confirm that:

* The workspace structure is present.
* Markdown files open correctly.
* Templates are available.
* Plugins are installed if desired.

## Next Steps

After the vault is ready:

1. Review the workspace structure.
2. Create your first Project or Area.
3. Capture new information in the Inbox.
4. Customize the vault according to your workflow.

Refer to the Reference Implementation for the canonical definitions of the Ohtli framework.
