# Workspace

## Overview

The workspace provides the navigation layer of the Ohtli vault.

It is designed to offer a simple and portable entry point that works in any
Markdown editor without relying on editor-specific functionality.

Navigation is implemented exclusively through Markdown and wiki links.

---

## Goals

- Provide a single entry point to the vault.
- Improve discoverability.
- Standardize navigation.
- Keep the vault editor independent.

---

## Principles

- Markdown first.
- Editor agnostic.
- Human readable.
- Consistent structure.
- Minimal maintenance.

---

## Components

The workspace consists of:

- Main workspace dashboard
- Section dashboards
- Section indexes

---

## Navigation

The workspace links to every major section of the vault.

Each section dashboard links back to the workspace.

Navigation should require no more than two clicks.
