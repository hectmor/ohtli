# Common Metadata

These properties are available for every note type.

| Property | Type | Required | Description |
|----------|------|----------|-------------|
| created | Date | Yes | Creation date |
| updated | Date | No | Last modification |
| tags | List | No | Classification tags |
| aliases | List | No | Alternative note names |

## Notes

Common metadata should remain independent from workflows.

Workflow-related properties belong to individual note types.
