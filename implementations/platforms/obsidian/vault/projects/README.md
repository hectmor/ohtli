# Projects

## Purpose

Projects are temporary efforts created to achieve a specific outcome.

Every project has:

- a goal
- active work
- an end

## What belongs here

- Active work
- Planning
- Notes
- Deliverables
- Tasks

## What does not belong here

- Permanent reference material
- Long-term responsibilities

## Workflow

Projects may be associated with one Area.

When completed:

Project → Archive

Reference notes created during the project may move to Knowledge.

## Examples

- Learn Rust
- Ohtli
- Renovate Office
