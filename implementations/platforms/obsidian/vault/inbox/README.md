# Inbox

## Purpose

The Inbox is the temporary landing zone for newly captured information.

Every note begins here before being organized elsewhere in the Vault.

## What belongs here

- Quick notes
- Ideas
- Meeting notes
- Links
- Drafts
- Captured tasks

## What does not belong here

- Permanent documentation
- Finished project notes
- Reference material
- Archived information

## Workflow

Process the Inbox regularly.

Each note should be moved to one of the following destinations:

- Projects
- Areas
- Knowledge
- Archive

The Inbox should never become long-term storage.

## Examples

- Idea for a new project
- Meeting notes
- Book recommendation
