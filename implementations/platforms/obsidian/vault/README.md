# Vault

The Vault is the official Obsidian workspace distributed with the Ohtli platform implementation.

It follows the Ohtli Specification and provides a clean starting point for organizing knowledge, projects, and responsibilities.

The Vault intentionally contains only the workspace structure and its documentation.

Platform-specific behavior, such as plugins, themes, templates, and application configuration, is managed outside the Vault and documented within the Obsidian platform implementation.

## Structure

* Inbox
* Areas
* Projects
* Knowledge
* Journal
* Reviews
* Templates
* Attachments
* Archive

Each directory has a single responsibility, ensuring the workspace remains simple, predictable, and easy to maintain.
