# Platform Implementations

Platform implementations adapt the Ohtli framework to specific software platforms.

Each implementation preserves the concepts defined by the Ohtli Specification while integrating with the capabilities and conventions of a particular platform.

A platform implementation may provide:

* A reference workspace or vault.
* Platform-specific configuration.
* Templates.
* Extensions or plugins.
* Themes or visual customization.
* Examples and documentation.

Platform implementations must not modify the Ohtli Specification. Their purpose is to implement it using the features available on each platform.
