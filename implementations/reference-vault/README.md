# Reference Vault

This directory contains the canonical Obsidian vault for the Ohtli framework.

It implements the workspace defined by the Ohtli Specification while taking advantage of the Obsidian ecosystem.

The vault is intended to serve as a starting point for new users and as the reference implementation for future extensions.

Users may use this vault directly or copy its contents into an existing Obsidian vault.

The workspace remains fully Markdown-based and portable outside Obsidian.
