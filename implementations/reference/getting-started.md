# Getting Started

## Prerequisites

No specific software is required.

The Reference Implementation is designed to work with any editor capable of opening Markdown files.

## Setup

1. Clone the repository.
2. Open the `implementations/reference` directory.
3. Begin organizing your information following the workspace structure.

## First Steps

A typical workflow begins with:

1. Capture information in the Inbox.
2. Organize it into Projects, Areas, or Knowledge.
3. Review your workspace regularly.
4. Archive completed or inactive material.

## Next

After becoming familiar with the workspace, you may customize it or adopt one of the official tool-specific implementations.
