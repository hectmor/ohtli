# Inbox

## Purpose

Store uncategorized information that has been captured but not yet processed.

## Contains

* Notes
* Ideas
* Tasks
* References

## Does Not Contain

* Long-term knowledge
* Active projects
* Permanent records

The Inbox should be reviewed and emptied regularly.

## Architectural Note

This folder is an implementation-level staging area for the Workflow
Model's Capture transformation. It is not a Domain Object. See
[Implementation Boundaries](../../../docs/architecture/implementation/README.md).
