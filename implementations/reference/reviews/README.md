# Reviews

## Purpose

Support regular evaluation of the workspace.

## Contains

* Weekly reviews
* Monthly reviews
* Quarterly reviews
* Annual reviews

## Does Not Contain

* Daily notes
* Project documentation

Reviews help maintain an organized and current workspace.

## Architectural Note

This folder stores outputs of the Workflow Model's Review
transformation. It is not a Domain Object. See
[Implementation Boundaries](../../../docs/architecture/implementation/README.md).
