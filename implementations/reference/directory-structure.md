# Directory Structure

```text
reference/
├── inbox/
├── areas/
├── projects/
├── knowledge/
├── journal/
├── reviews/
├── templates/
├── attachments/
└── archive/
```

## Design Principles

* One purpose per directory.
* Predictable organization.
* Human-readable structure.
* Tool-independent layout.
* Minimal hierarchy.

The directory structure follows the Filesystem Specification defined in the Core Specification.
