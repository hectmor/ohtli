# Reference Implementation

The Reference Implementation is the canonical implementation of the Ohtli framework.

Its purpose is to demonstrate how the concepts defined in the Core Specification are applied in practice using only Markdown files and a standard filesystem.

## Goals

* Provide a complete working workspace.
* Remain tool-independent.
* Serve as the foundation for future implementations.
* Act as the reference for documentation and examples.

## Scope

This implementation includes:

* Workspace structure
* Directory organization
* Usage documentation

It intentionally does not include:

* Tool-specific configuration
* Automation
* Plugins
* AI integrations

## Structure

* `inbox/`
* `areas/`
* `projects/`
* `knowledge/`
* `journal/`
* `reviews/`
* `templates/`
* `attachments/`
* `archive/`

See the accompanying documentation for details on how the workspace is intended to be used.
