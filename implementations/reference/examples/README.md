# Examples

This directory contains canonical examples that demonstrate how the Ohtli framework can be applied in practice.

The examples illustrate the intended use of the core entities and the relationships between them while remaining independent of any specific tool or platform.

Each example is based on the canonical templates provided by the Reference Implementation.

## Structure

The examples are organized by entity type.

* `area/`
* `project/`
* `knowledge/`
* `journal/`
* `review/`
* `workflow/`

The `workflow` example demonstrates how information moves through the workspace, from initial capture to periodic review.

## Purpose

These examples are provided for learning and reference purposes.

They are intentionally concise and focus on demonstrating the Ohtli workflow rather than representing complete real-world projects.

Users are encouraged to adapt, extend, or remove the examples according to their own needs.
