# Example Workflow

This example demonstrates how information flows through the Ohtli framework.

```text
Inbox
    ↓
Project
    ↓
Knowledge
    ↓
Journal
    ↓
Review
```

## Flow

1. Capture an idea in the Inbox.
2. Create a Project when the work has a defined objective.
3. Record reusable information as Knowledge.
4. Log progress in the Journal.
5. Evaluate outcomes during a Review.

This workflow illustrates how the core entities work together while remaining independent and reusable.
