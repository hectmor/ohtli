# Ohtli

> **A personal operating framework for transforming information into consistent execution.**

**Ohtli** (from the Nahuatl word *ōhtli*, meaning *path* or *journey*) is a personal operating framework designed to help individuals capture information, build knowledge, make better decisions, and execute consistently.

Rather than being another note-taking system or productivity methodology, Ohtli defines a structured way of managing work and knowledge that is independent of any specific tool. Its first reference implementation is built with Obsidian, but the framework itself is platform-agnostic.

---

# Vision

Information alone has little value unless it leads to action.

Ohtli provides a clear path from capturing ideas to executing meaningful work while continuously learning and improving.

```text
Information
    ↓
Knowledge
    ↓
Decision
    ↓
Execution
    ↓
Learning
    ↓
Improvement
```

---

# Core Principles

* **Capture First** — Never trust memory.
* **Single Source of Truth** — Every piece of information has one authoritative location.
* **Markdown First** — Data should remain simple, portable, and future-proof.
* **Tool Independence** — The framework must not depend on a specific application.
* **Automation Follows Process** — Automate only after the workflow is stable.
* **Simplicity Wins** — Favor simple systems over clever ones.
* **Review Creates Trust** — Regular reviews keep the system reliable.
* **Knowledge Should Lead to Action** — Documentation exists to support execution.

# Architecture

Ohtli is organized into several architectural layers:

1. Filesystem
2. Metadata
3. Domain Model
4. Workflows
5. Views
6. Automation

Each layer builds upon the previous one while remaining loosely coupled.

# Design Philosophy

Ohtli is designed as a framework rather than an application.

The objective is not to prescribe a specific tool, but to define a methodology that can evolve over time while remaining understandable, maintainable, and independent of any particular technology.

---

# Name

**Ōhtli** is a Nahuatl word meaning **path**, **road**, or **journey**.

The name reflects the purpose of the framework: guiding information through a deliberate path until it becomes knowledge, decisions, execution, and continuous improvement.
