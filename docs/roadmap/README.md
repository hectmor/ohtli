# Ohtli Roadmap

Ohtli is a portable personal operating system for thinking, knowledge management,
and execution.

The roadmap is organized into incremental phases. Each phase delivers a stable
set of capabilities that become the foundation for the next phase.

| Phase | Name | Status |
|-------|------|--------|
| 1 | Platform Foundation | ✅ Completed |
| 2 | Domain Architecture | 🚧 In Progress |
| 3 | Workflow | ⏳ Planned |
| 4 | User Experience | ⏳ Planned |
| 5 | Automation | ⏳ Planned |
