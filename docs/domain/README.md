# Domain Model

The domain model defines the core concepts of Ohtli and the relationships between them.

It provides a shared vocabulary that is independent of any specific implementation or tool.

The purpose of the domain model is to ensure that every concept has a clear definition, a single responsibility, and well-defined relationships with other concepts.

## Documents

* `entities.md` — Defines the core entities of Ohtli.
* `relationships.md` — Defines how those entities interact.

## Design Goals

* Establish a common language.
* Separate concepts from implementation.
* Minimize ambiguity.
* Support long-term maintainability.
