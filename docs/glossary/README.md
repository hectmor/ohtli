# Glossary

The Glossary defines the vocabulary used throughout the Ohtli framework.

Its purpose is to ensure that every architectural term has a single, consistent meaning.

Whenever possible, documentation should use glossary terms consistently and avoid introducing synonyms for established concepts.

## Documents

* `terms.md` — Defines the standard terminology used by Ohtli.

## Goals

* Establish a common vocabulary.
* Reduce ambiguity.
* Improve consistency.
* Support long-term maintainability.
