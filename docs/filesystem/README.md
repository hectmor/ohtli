# Filesystem

The Filesystem defines how information is organized on disk.

Its purpose is to provide a predictable, portable, and tool-independent structure for storing information.

The filesystem is the physical representation of the Ohtli domain model.

## Documents

* `directory-structure.md` — Defines the directory hierarchy.
* `naming-conventions.md` — Defines naming rules for files and directories.

## Goals

* Ensure portability.
* Support version control.
* Minimize ambiguity.
* Keep the structure predictable.
