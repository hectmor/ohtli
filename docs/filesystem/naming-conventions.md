# Naming Conventions

Consistent naming improves readability, searchability, and portability.

## General Rules

* Use lowercase.
* Use kebab-case.
* Avoid spaces.
* Avoid special characters.
* Prefer descriptive names.
* Keep names stable.

## Files

Examples:

```text
project-charter.md
weekly-review.md
meeting-notes.md
research-summary.md
```

## Directories

Examples:

```text
projects/
knowledge/
machine-learning/
quantum-computing/
```

## Dates

Use ISO 8601 when dates are part of a filename.

Example:

```text
2026-07-20-daily-journal.md
```

## Identifiers

Do not use numeric identifiers unless they have domain meaning.

Prefer meaningful names over arbitrary numbers.

## Principle

A filename should be understandable without opening the file.
