# Integration Points

Automation may interact with the following parts of Ohtli.

## Templates

Generate standardized documents.

---

## Metadata

Read and update metadata when appropriate.

---

## Views

Generate dashboards, reports, and summaries.

---

## Reviews

Assist in preparing periodic reviews.

---

## Search

Provide semantic or keyword-based retrieval.

---

## Knowledge

Extract, summarize, classify, or relate information.

---

## External Systems

Automation may integrate with external tools such as:

* Git
* Python
* AI assistants
* Task managers
* Calendars
* Cloud storage

These integrations should remain optional and should never become requirements for using Ohtli.
