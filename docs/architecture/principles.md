# Architecture Principles

These principles guide every architectural decision in Ohtli.

## Tool Independence

The framework must not depend on a specific application or plugin.

## Single Source of Truth

Every piece of information has one authoritative location.

## Markdown First

Knowledge is stored in plain Markdown whenever possible.

## Separation of Concerns

Each architectural layer has a single responsibility.

## Simplicity

Prefer the simplest solution that satisfies the requirements.

## Consistency

Naming, structure, and workflows should remain predictable across the framework.

## Incremental Evolution

The framework evolves through small, well-defined changes rather than large redesigns.

## Documentation Before Automation

Processes should be documented and stabilized before they are automated.

## Traceable Decisions

Significant architectural decisions are documented using ADRs.

## Long-Term Maintainability

Every design decision should prioritize clarity and sustainability over short-term convenience.
