# Journal Entry

## Purpose

Support personal thinking.

## Identity

A journal entry captures thoughts associated with a specific moment in
time.

## Responsibilities

- Capture ideas.
- Capture reflections.
- Capture observations.

## Essential Attributes

- Date
- Content

## Lifecycle

Created.

Contextual presence (Operational vs. Historical) is a separate
dimension, independent from Lifecycle, defined by the Archive Workflow
(`Lifecycle Independence`, `archive-workflow.md`). It is not a
Lifecycle value.
