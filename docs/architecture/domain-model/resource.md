# Resource

## Purpose

Represent synthesized knowledge.

## Identity

A resource represents knowledge produced through learning, analysis,
or experience.

## Responsibilities

- Explain concepts.
- Organize knowledge.
- Support projects and areas.

## Essential Attributes

- Title
- Content
- Topic

## Lifecycle

- Draft
- Published

Contextual presence (Operational vs. Historical) is a separate
dimension, independent from Lifecycle, defined by the Archive Workflow
(`Lifecycle Independence`, `archive-workflow.md`). It is not a
Lifecycle value.
