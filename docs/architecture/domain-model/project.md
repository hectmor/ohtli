# Project

## Purpose

Deliver a finite outcome.

## Identity

A project is uniquely identifiable regardless of its implementation.

## Responsibilities

- Define an objective.
- Organize work.
- Track progress.
- Produce outcomes.

## Essential Attributes

- Title
- Objective
- Status

## Lifecycle

- Created
- Active
- On Hold
- Completed

Contextual presence (Operational vs. Historical) is a separate
dimension, independent from Lifecycle, defined by the Archive Workflow
(`Lifecycle Independence`, `archive-workflow.md`). It is not a
Lifecycle value.
