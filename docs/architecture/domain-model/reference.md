# Reference

## Purpose

Preserve external information.

## Identity

A reference represents an external source of information.

## Responsibilities

- Preserve original information.
- Support knowledge creation.

## Essential Attributes

- Title
- Source
- Type

## Lifecycle

Captured.

Contextual presence (Operational vs. Historical) is a separate
dimension, independent from Lifecycle, defined by the Archive Workflow
(`Lifecycle Independence`, `archive-workflow.md`). It is not a
Lifecycle value.
