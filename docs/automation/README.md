# Automation

Automation extends the capabilities of Ohtli by reducing repetitive work while preserving the framework's principles.

Automation is optional.

The framework must remain fully usable without any automation.

## Documents

* `automation-principles.md` — Defines the principles governing automation.
* `integration-points.md` — Defines where automation may interact with the framework.

## Goals

* Reduce repetitive work.
* Improve consistency.
* Preserve human control.
* Maintain tool independence.
* Support multiple implementations.
