# Automation Principles

Automation should assist users without becoming a dependency.

## Human in Control

Automation supports decision-making but never replaces it.

---

## Optional

Every automated process should have a manual alternative.

---

## Non-Intrusive

Automation must not alter the domain model or workflow.

---

## Deterministic

Whenever possible, automation should produce predictable and reproducible results.

---

## Transparent

Automated actions should be understandable and traceable.

---

## Tool Independent

Automation should interact with the framework through documented interfaces rather than application-specific behavior.

---

## Incremental

Automation should evolve independently from the core specification.
