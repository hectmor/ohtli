# Front Matter

Ohtli uses YAML Front Matter as the standard metadata format.

Example:

```yaml
---
title: Example Project
type: project
status: active
created: 2026-07-20
updated: 2026-07-20
tags:
  - data-engineering
---
```

## Principles

* Every metadata field has a defined purpose.
* Metadata should be machine-readable.
* Metadata should remain human-readable.
* Document content is the primary source of knowledge.
* Metadata should be concise.
* Avoid duplicate information between metadata and content.
