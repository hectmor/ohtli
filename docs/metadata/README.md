# Metadata

Metadata provides structured information about documents.

It enables organization, filtering, automation, and interoperability while remaining independent of any specific application.

Metadata complements the document content but never replaces it.

## Documents

* `front-matter.md` — Defines the metadata format.
* `properties.md` — Defines the standard metadata properties.

## Goals

* Standardize document description.
* Enable automation.
* Improve discoverability.
* Support interoperability.
* Keep metadata minimal and meaningful.
