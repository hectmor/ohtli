# Versioning

Versioning defines how Ohtli evolves while preserving stability and compatibility.

Its purpose is to provide a predictable release model for both the framework specification and future implementations.

## Documents

* `semantic-versioning.md` — Defines the version numbering scheme.
* `release-process.md` — Defines how releases are planned and published.

## Goals

* Provide predictable evolution.
* Preserve compatibility.
* Communicate the impact of changes.
* Support long-term maintenance.
