# Views

Views present information without owning it.

They allow users to visualize, filter, summarize, and navigate information stored in the Ohtli domain model.

Views are implementation-independent and may be realized through queries, dashboards, reports, or custom interfaces.

## Documents

* `view-types.md` — Defines the standard view types.
* `design-principles.md` — Defines the principles for designing views.

## Goals

* Improve navigation.
* Support decision-making.
* Reduce information overload.
* Present information consistently.
* Remain independent of implementation technologies.
