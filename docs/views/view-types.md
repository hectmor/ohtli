# View Types

Ohtli defines a small set of reusable view types.

## Dashboard

Provides a high-level overview of one or more domain entities.

Examples:

* Personal Dashboard
* Project Dashboard
* Area Dashboard

---

## List

Displays collections of entities.

Examples:

* Active Projects
* Open Reviews
* Knowledge Articles

---

## Timeline

Presents information in chronological order.

Examples:

* Journal Entries
* Project History
* Review History

---

## Report

Summarizes information for analysis or communication.

Examples:

* Weekly Review
* Monthly Summary
* Project Status Report

---

## Search

Retrieves information matching user-defined criteria.

Search is a dynamic view and never modifies data.

---

## Graph

Visualizes relationships between entities.

Graphs support exploration rather than data management.
