# Entity Lifecycles

This document defines the lifecycle of the primary entities in Ohtli.

## Project

```text
Idea
    ↓
Planned
    ↓
Active
    ↓
Completed
    ↓
Archived
```

## Knowledge

```text
Capture
    ↓
Organize
    ↓
Refine
    ↓
Reference
```

Knowledge is continuously refined and has no terminal state.

## Review

```text
Scheduled
    ↓
Performed
    ↓
Completed
```

Reviews are recurring activities that support continuous improvement.
