# Execution System

The Execution System defines how work flows through Ohtli.

Its purpose is to transform information into consistent execution through a simple, repeatable process.

The execution system is independent of any specific tool or implementation.

## Documents

* `workflow.md` — Defines the execution workflow.
* `lifecycle.md` — Defines the lifecycle of the core entities.

## Goals

* Reduce friction.
* Support consistent execution.
* Establish predictable workflows.
* Enable future automation.
