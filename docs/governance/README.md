# Governance

Governance defines how Ohtli is maintained, evolved, and improved over time.

Its purpose is to ensure that architectural integrity is preserved while allowing the framework to grow.

Governance applies to the framework itself, not to user content.

## Documents

* `decision-process.md` — Defines how architectural decisions are made.
* `contribution-model.md` — Defines how changes are proposed and accepted.

## Goals

* Preserve architectural consistency.
* Enable sustainable evolution.
* Encourage transparent decision-making.
* Maintain long-term stability.
